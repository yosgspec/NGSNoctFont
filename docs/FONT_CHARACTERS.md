# 収録文字

## 現在の収録文字

lc1版・lc2版には、空白、数字 `0-9`、大文字 `A-Z`、各版の小文字 `a-z`、記号45字の計108文字が入っています。空白を含む印字可能なASCII 95字と、追加記号13字です。

LC1は全字の送り幅500 unitsの等幅です。LC2は字形ごとに送り幅が変わるプロポーショナルです。

## 記号一覧

```text
!"#$%&'()*+,-./:;<=>?@[\]^_`{|}~
£¥©®–—‘’“”…€™
```

1行目がASCII記号32字、2行目が追加記号13字です。追加記号のUnicodeは順に、U+00A3、U+00A5、U+00A9、U+00AE、U+2013、U+2014、U+2018、U+2019、U+201C、U+201D、U+2026、U+20AC、U+2122です。

## 図面からの取得

ASCII記号の上段は左から `!` 〜 `^` の26字、下段は `_` `` ` `` `{` `|` `}` `~` の6字です。下段には続けて追加記号13字を並べています。

記号45字のうち37字はグループ、8字は単独図形です。さらに、1本だけグループ外にある線分は、接している記号の一部として取り込みます。
