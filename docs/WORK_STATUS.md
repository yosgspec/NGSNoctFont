# 作業状況

更新日: 2026-11-21

## 字形

- M系の `l` はP系のSVGと同じ内容に変更済みです。
- lc2の `w/m/x/z` と、記号 `; ! €` は原稿から抽出した形に戻しました。
- 基本133字では、パスの端点をつないで `M` を395個から228個へ167個削減しています。`d` 属性全体は14,656文字から10,242文字です。

## MF/PF

- 参照図に合わせるため、MF/PFの `g/p/q` はそれぞれ別形状として新しく作成しました。既存字形のコピーではありません。
- SVGは `src/charsvg/` 配下のサブディレクトリに配置し、MF/PF用の `g/p/q` は `lowercase_mf` / `lowercase_pf` に配置します。
- MFは通常のMと同じ等幅送り幅500 units、PFはプロポーショナルです。フォント垂直メトリクスは通常版から400 units（Y座標2単位）低くします。
- MF/PFでは `|` のベースライン以下を切り取ります。
- 現在の字形プレビューは `build/short_glyph_preview.png` です。参照図との最終的な見た目の確認は未完了です。

## ビルド状況

- M/P/MF/PF、Regular/Boldの8書体を生成し、`NGSNoct.ttc` にまとめます。
- Boldはウェイト700、Regularの1.4倍の線幅です。
- Release検証は8書体すべてで成功し、各108文字を確認しています。検証時の出力先は `build/release/` で、公開はしていません。
